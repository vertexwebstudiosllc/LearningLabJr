# Counting Drum sounds

These three original percussion effects are generated from decaying sine tones, with no external samples. They are mono, 22,050 Hz, 16-bit PCM WAV files, each half a second long. The small, medium and big drums use base frequencies of 240, 160 and 95 Hz respectively, with a brief pitch drop and a quiet overtone.

The game plays them quietly alongside Ruth's drum-name recordings during demonstrations and on the child's taps. They respect the existing voice/audio prompt preference and stop when the game leaves the foreground.

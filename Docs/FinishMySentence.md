# Finish My Sentence

36 sentence prompts cover everyday routines, animals, food, music, nature, and travel. Each presents three shuffled pictures and one unambiguous answer. Incorrect choices offer a gentle retry; correct choices reveal the completed sentence while Ruth says the answer word.

Sentence IDs are saved when first displayed, including interrupted rounds. Reopening continues with unseen content. After all 36 have been shown, the collection stays complete; there is no automatic recycling. Progress is local to the device/app data, shared by children using that installation.

Artwork uses existing transparent cutouts and vector props. The ball is rendered as a vector instead of a legacy raster. Ruth recordings are required for every prompt, answer word, and feedback line.

Validation fixtures check all 36 sentences across interrupted sessions, exhaustion, invalid answers, duplicate taps, an artwork contact sheet on a purple background, narration coverage, and an eight-round UI walkthrough.

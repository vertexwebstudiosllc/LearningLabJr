# A Cozy Nest

Ten four-step projects replace the single nest activity: bird nest, doghouse, cat toy, pet bed, rabbit tunnel, little bridge, flower box, bug hotel, toy boat, and picnic table. The nest always comes first; the remaining nine are shuffled without repeats. Replay and reopening avoid the previous second project.

Each project shows a faint construction plan. Children listen to Ruth and tap the pictured piece named in the current step. Completed pieces fill the scene, and the next outline is emphasized. A different choice prompts a gentle hint without losing progress. An explicit next button lets children admire each finished project before continuing. Replay starts a fresh nest.

All artwork is drawn as SwiftUI vector pieces, with no external image-generation dependency. The game uses the shared narration and accessibility controls. All 91 instruction, retry, and celebration lines are bundled in Ruth's generative Polly voice for offline playback.

Native coverage runs 100 complete sessions and verifies project variety, nest-first ordering, previous-second exclusion, stale/duplicate/unknown actions, step progression, vector paths, and exact Ruth coverage. A simulator playthrough builds all ten projects, exercises incorrect choices, checks completion and replay, and reopens the game.

# Counting and habitat artwork cleanup

Number Picnic, Touch & Count, Picnic Share, Which Has More?, and Ticket Train now use the explicit clean literacy artwork resolver for every food and animal in their collections. Artwork is selected by the item identifier, rather than the old image filename. Existing clean cutouts and transparent native/platform illustrations preserve the game background around each object. Strawberries use the existing native food drawing; blueberries and raspberries have new native drawings that remain legible in small counting grids.

Habitat Helpers now uses verified clean dolphin, shark, seahorse, farm-animal, and duck cutouts. Octopus and goose use transparent platform illustrations, matching the game's existing insect, bird, and jungle-animal approach. Habitat scenery icons remain intentional representations of the homes.

These are presentation changes only: quantities, answer choices, progression, animal/habitat pairings, accessibility labels, and Ruth narration keys are unchanged.

Validation: 112 native tests and the six-game simulator walkthrough passed with recorded Ruth narration enabled. Artwork coverage checks include all twelve counting fruits, twelve counting animals, and twenty-four habitat animals. Rendered galleries were reviewed on a colored background to expose unwanted rectangles, along with simulator layouts at game sizes.
